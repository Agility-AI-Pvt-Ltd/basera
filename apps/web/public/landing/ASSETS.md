# Landing images (reference)

The Stitch landing page loads images from:

- **`@tailz-club/assets`** — hero (`hero_img.png`), pet photos, logo, activity backgrounds
- **`/landing-page/`** — app screenshots: `adoption_page.png`, `community_page.png`, `training_page.png`, `nutrition_page.png`, `about_bg.png`

No files are required in this `/landing/` folder unless you override paths in `apps/web/src/landing/stitch/landingAssets.ts`.
